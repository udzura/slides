# Fukuoka Wasm #1

8枚目の `svg-hover` クラスを付けたスライドだけ、WATを行単位のインラインSVGに変換する試作。
コードは `index.md` の通常のコードフェンスで編集する。

```sh
python3 fukuokawasm-1/build.py
```

リポジトリルートから実行する場合のコマンド。ビルドスクリプトは他の作業ディレクトリからでも実行可能。
MarpでHTML生成後、マークしたスライドのWATだけ変換する。
通常の `marp` コマンドだけで再生成するとSVG試作は含まれない。

行の横幅全体がホバー対象。対象行は明るい背景（#fffdf9）と朱色のマーカー、他行は濃い背景（#d3d5c9）。文字の不透明度は変えない。
ホバー中は枠の上下の余白も同じ濃い背景にする。切り替えは120ms。行から離れると全行を通常表示する。
印刷では全行を通常表示し、動きを減らす設定ではtransitionを無効にする。

プレビュー: http://127.0.0.1:8767/fukuokawasm-1/#8

「Cの関数へ戻るまで」（18枚目）の図は `images/sjlj-flow.svg` で編集する。
ビルドスクリプトがこの図もインライン化し、HTML内で各要素のホバーが動くようにする。
ホバー対象は明るい背景と朱色の枠、他の要素は濃い背景になる。文字の濃さは維持する。
Tabで図の各要素へ移動した場合も強調する。印刷時は通常表示に戻し、動きを減らす設定に対応する。
通常のMarpだけで生成した場合も図は画像として表示されるが、要素単位のホバーはビルドスクリプト経由で有効になる。
